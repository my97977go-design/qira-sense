# 排行榜维护

## 运行

双击 Start-Qira.cmd，或运行 `node scripts/serve.mjs`。页面与 `/api/leaderboard` 共用一个服务，无额外依赖、无需注册系统。纯静态托管只能显示演示榜单；要接收真实成绩，请运行附带 Node 服务。

默认绑定本机 127.0.0.1:5188。修改 PORT 可更换端口。设置 HOST 为演示机器局域网地址或 0.0.0.0 后，可让同一网络的设备访问这台服务；没有在本次任务中发布公网网站。

开发时先设置 PORT=5191 运行服务，再运行 npm run dev；Vite 会把 /api 代理到 5191。

## 数据

- `src/data/leaderboard.json`：24 条演示数据，三个游戏各 8 条，demo=true。
- `runtime/leaderboard.json`：真实上传成绩，首次上传时生成。重新部署前备份此文件；不要用空文件覆盖。
- QIRA_RANKING_FILE 环境变量可指定数据文件的绝对路径，便于代码更新时保留数据。
- 浏览器 `qira-last-scores-v1` 保存各游戏上一次得分；`qira-nickname` 保存上次昵称。

GET /api/leaderboard 返回合并的榜单。POST 接受 mode、nickname、score、accuracy、runId。服务端验证格式、字符长度、范围和游戏类型；同一 runId 重试不会重复记分，写入临时文件后替换保存。最多保留最近 3000 条实际成绩，每个榜单窗口展示前 30 名，同分按先提交者在前。

这是免登录展示榜：昵称可重复，成绩来自客户端游戏结算，没有身份认证或服务端比赛回放校验。不同手动拍速的练习成绩尚未细分难度榜，因此用途是课堂互动激励，而非正式竞赛认证。

## 验证

15 项自动测试通过，含成绩校验、重复提交、保存后重载。实际完成第二关后自动出现提交弹窗，填昵称上传成功；新浏览器看到相同成绩；重玩显示上次 3000 分；游戏中打开榜单先暂停。测试数据只写入工作目录独立文件，交付包不含测试玩家成绩。
