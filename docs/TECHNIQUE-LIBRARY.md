# 技法资料库与课程维护

## 教师如何添加与修改

进入“技法资料库”，点击“教师维护”。选择条目后点击“编辑此条目”，修改解释和教学提示，保存后声音地图自动采用新内容。新增条目时填写各个说明字段，选择一个现有动画模板和标识色。只有确认原声片段确实对应该技法后，才关联人工标注；可不选例证，作为概念资料。

修改先保存在当前浏览器的 localStorage，并非云端共享数据库。每次维护后建议“导出资料库”备份，其他设备可通过“导入资料库”恢复。导入替换当前整份技法资料，不会替换录音、人工标注或课程进度。

如要让所有新打开的浏览器使用维护结果，将导出的 JSON 替换 `src/data/techniques.json`，运行 `npm run build`，分发新的 dist。现有浏览器仍优先采用其本机资料；可以导入新版 JSON 更新。

## 三层数据关系

- `src/data/techniques.json`：技法定义、解释、教学问题、动画模板和例证关联。
- `src/data/song.json`：录音元数据与人工标注区间，保留原表的行号、名称和来源。
- `src/data/course.json`：品牌、课题展示信息、章节与关卡目标、通关阈值和前置关卡。

技法通过 `examples[].songId` 关联曲目，通过 `examples[].annotationIds` 关联该曲目的人工区间。动画由 `animation` 指定，不要求技法编号等于动画编号，因此新增技法可以复用模板。

```json
{
  "schemaVersion": 1,
  "title": "中国音乐技法资料库",
  "entries": [{
    "id": "large-up-glide",
    "name": "大上滑音",
    "color": "#e3c394",
    "animation": "large-up-glide",
    "shortExplanation": "大上滑音不是简单的升高，而是在短时间内完成明显的、具有方向性的音高移动，形成向上的张力。",
    "pitchCue": "同时观察上行幅度与所用时间。",
    "listeningCue": "注意滑行的跨度、速度和前后乐句。",
    "aestheticPrompt": "这种上行让你产生怎样的听感？为什么？",
    "commonConfusion": "不要仅凭终点更高，就把普通上滑判为大上滑。",
    "question": "对比两个片段，哪一段上行更明显？",
    "sourceNote": "教学解释草稿，录音例证待教师确认。",
    "reviewStatus": "teaching-draft",
    "examples": []
  }]
}
```

已确认的例证结构可参考 `{"songId":"daqiban-upload-001","annotationIds":["manual-01"]}`。这里只展示结构，不表示 manual-01 已确认是大上滑。

导入校验：schemaVersion 为 1；条目编号唯一，只使用小写字母、数字、连字符；必填文本不为空且不超过 1500 字符；颜色为六位 HEX；动画属于内置模板；例证关联有合法数组结构。未知或尚未接入的曲目关联保留在数据中，当前页面只呈现能够解析到实际录音区间的例证。

## 资料准确性

当前教学解释是可修订的初稿，审美提问是开放问题，不是自动评分答案。原表写作“滑柔”，保留原词并标注术语待复核。大上滑与垫弓当前没有单独确认的原声例证，不自动套用其他片段。资料库显示的动画是示意图；播放时的音高曲线才来自音频测量。基频估计在噪声、复音、快速装饰音和倍频歧义处可能偏差，应结合原声判断。

## 未来接入两首新曲

当前三关均使用《大起板》，三个章节只开放第一章。接入新曲需要真实音频、曲名/乐器信息、人工标注时间范围和技法编号；不能只修改“已开放”文字。

开发步骤：
1. 将录音放入 `public/audio`，建立独立 song JSON、唯一 songId 与音频哈希。
2. 将单曲 `loadSong`、播放缓存与 BPM 缓存改为按 songId 管理，切曲时释放旧播放源并加载新音频。
3. 为新曲关联技法例证，明确秒级区间与逐音点位精度。
4. 为章节配置真实的三个学习任务，并将课程进度键按版本/曲目区分。
5. 验证音高范围、BPM 倍半速、音符密度、难度和完整通关，再开放章节。

内置目录已经预留第二、第三章展示，但多曲目播放运行时仍需上述扩展。新增概念技法本身不需要改代码；新增一种全新动画形状，需要在 `TechniqueRibbon.jsx` 与动画枚举中增加模板。

## 隐私与技术边界

音高、节拍分析和学习记录均在浏览器内处理，无模型 API 调用，也不上传录音或听感。这里的自动分析是音频信号处理，不声称已经实现自动技法识别、语义诊断或审美水平评测。后续研究可以在此基础上增加经验证的模型。
